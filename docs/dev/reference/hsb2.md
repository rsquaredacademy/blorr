# `High School and Beyond Data Set`

Source:
[`R/blr-data-hsb.R`](https://github.com/rsquaredacademy/blorr/blob/HEAD/R/blr-data-hsb.R)

`hsb2.Rd`

A dataset containing demographic information and standardized test
scores of high school students.

## Usage

``` r
hsb2
```

## Format

A data frame with 200 rows and 11 variables:

- id:

  id of the student

- female:

  gender of the student

- race:

  ethnic background of the student

- ses:

  socio-economic status of the student

- schtyp:

  school type

- prog:

  program type

- read:

  scores from test of reading

- write:

  scores from test of writing

- math:

  scores from test of math

- science:

  scores from test of science

- socst:

  scores from test of social studies

- honcomp:

  1 if write \> 60, else 0
